# ✅ To-Do Web App

A responsive and interactive **To-Do Web App** built using HTML5, CSS3, and Vanilla JavaScript.

The application helps users manage their daily tasks by adding, editing, completing, and deleting tasks.

## 🌐 Live Website

👉 **[View Live Website](https://gulabhussain.github.io/To-Do-Web-App/)**

## 📌 About the Project

This project is created as part of the **Web Development & Designing – Level 2, Task 3**.

The application provides a simple, modern, and user-friendly interface for managing pending and completed tasks.

## ✨ Features

* ➕ Add new tasks
* ✅ Mark tasks as completed
* ↩️ Move completed tasks back to pending
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* 📊 Display pending task count
* 📊 Display completed task count
* 🕒 Show task creation time
* 💾 Save tasks using Local Storage
* 🔄 Tasks remain available after page refresh
* 📱 Fully responsive design
* 🎨 Modern and attractive user interface
* ⚠️ Empty task validation
* 💬 Friendly empty-state messages
* 🖱️ Interactive buttons and hover effects

## 📋 Task Management

The application provides two separate sections:

### 📝 Pending Tasks

Newly added tasks are displayed in the **Pending Tasks** section.

Users can:

* Complete a task
* Edit a task
* Delete a task

### ✅ Completed Tasks

When a pending task is marked as completed, it automatically moves to the **Completed Tasks** section.

Users can also use the **Undo** button to move a completed task back to pending.

## 💾 Local Storage

The application uses browser **Local Storage** to save tasks.

This means tasks remain available even after:

* Refreshing the page
* Closing and reopening the browser
